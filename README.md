# RuneAssist Flipping

RuneLite plugin for Grand Exchange flipping. Based on [Flipping Copilot](https://github.com/cbrewitt/flipping-copilot), used under the BSD 2-Clause License (see `LICENSE`).

Sideload the built jar, or wait for Plugin Hub publishing. Plugin class: `com.runeassist.flip.controller.FlippingCopilotPlugin`.

## Build

Requires JDK 11+.

```
./gradlew jar
```

On Windows: `gradlew.bat jar`. The jar is written to `build/libs/`.
